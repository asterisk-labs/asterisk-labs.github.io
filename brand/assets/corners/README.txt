asterisk labs — corner frame
============================
The corner triangles are part of the brand. Use them as a light frame on
full-bleed layouts (slides, posters, social, covers).

files (svg = vector, png = raster, both transparent)
  corners-slide-16x9      1920x1080 presentation slide
  corners-slide-4x3       1440x1080 presentation slide
  corners-square          1080x1080 social post
  corners-poster-portrait 2:3 poster / cover
  corners-a4-portrait     A4 document, portrait
  corners-a4-landscape    A4 document, landscape
  corner-unit-tl          one corner tile, for custom sizes (mirror for others)
  corners-web.html        copy-paste HTML+CSS overlay for web pages

how to use
  1. add the matching overlay as the TOP layer, full-bleed (edge to edge).
  2. keep text and logos inside a safe margin — never let content touch or
     sit under the triangles.
  3. use ONE size of frame per surface; don't resize individual corners.
  4. don't recolour, rotate, or move the triangles off the corners.
